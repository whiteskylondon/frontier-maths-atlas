Backprop as automatic differentiation

Backpropagation isn't a neural-net trick — it's the chain rule run backward through a graph. Here it prices a call option and hands back every Greek in one sweep.

LevelUS Senior undergrad → graduateFR Master 1 · ENSAE 2A

Lesson 9's optimizers all consumed one object: the gradient ∇L. This lesson is about how that gradient is actually manufactured. The idea, in plain words: write any calculation — a loss, a price — as a computation graph of tiny steps, evaluate it once left-to-right (the forward pass), then walk the same graph once right-to-left pushing sensitivities from the output back to every input (the backward sweep). Each step only needs its own local derivative; the chain rule stitches them together. That bookkeeping scheme is reverse-mode automatic differentiation, and its punchline is economic, not mathematical: the entire gradient — a million partial derivatives, or all of an option's Greeks — costs a small constant times one evaluation.

The vocabulary, in plain words
  • computation graphthe recipe written as single steps. Each node is one elementary operation (a log, a product, a Φ); an edge means "this value feeds that step." Every pricing formula and every neural network is such a graph.
  • forward passrun the recipe input → output, caching every intermediate value. This is just evaluating the function — one pricing.
  • adjoint v̄a node's sensitivity: v̄ = ∂(final output)/∂(this node). Say "v-bar." The backward sweep fills these in, output → inputs. For an input node, the adjoint IS the derivative you wanted.
  • the tapethe cache of forward values the sweep reads back. Local derivatives like ∂(σ√T)/∂σ = √T need the forward values, so all of them must stay alive until the sweep returns.
  • forward modethe mirror image: push one input's tiny perturbation downstream. One pass per input; no tape needed. Formally a Jacobian-vector product (JVP).
  • reverse modepull the output's sensitivity upstream via adjoints. One pass per output. Formally a vector-Jacobian product (VJP). Backprop = reverse mode on a scalar loss.
  • Greeka derivative of a price with respect to one of its inputs: delta ∂C/∂S, vega ∂C/∂σ, rho ∂C/∂r. One price, many inputs — exactly the shape reverse mode devours.
The chain rule on a graph

Both modes are the same chain rule, swept in opposite directions. Forward mode carries a tangent v̇ (how much each node moves per unit wiggle of one chosen input); reverse mode carries an adjoint v̄ (how much the output moves per unit wiggle of this node). A node that feeds several places influences the output through every branch, so contributions add — the most-missed rule in hand-rolled backprop:

  • v̇ⱼtangent of node j, propagated input → output. Seed one input with v̇ = 1, all others 0; the output's tangent is one column of the Jacobian (a JVP).
  • v̄ᵢadjoint of node i, propagated output → input. Seed the output with v̄ = 1; every input's adjoint is one entry of the gradient (a VJP row).
  • ∂vⱼ/∂vᵢthe local partial attached to one edge. Known in closed form for each elementary op — that's what makes AD exact, unlike finite differences.
  • pa(j), ch(i)parents feed j; children are fed by i. The sums run over edges, so each sweep touches each edge once — the seed of the cost theorem below.

Now the taxonomy. For f: ℝᵏ → ℝᵐ, forward mode rebuilds the full Jacobian in k passes (one per input); reverse mode in m passes (one per output). So reverse wins when m = 1 and k is large — a scalar loss over a million weights, a single book PnL over hundreds of risk factors. Forward wins when k is small or m is large: one shocked input propagating to a whole book of outputs.

The worked example — Black–Scholes as a graph
  • S, Kspot price and strike. S is the input the desk bumps for delta.
  • σ, T, rimplied volatility, time to expiry (years), risk-free rate. Their partials are vega, ∂C/∂T, rho.
  • Φ, φstandard normal CDF and density. Evaluated here with Hart's (1968) double-precision rational approximation — error ≈ 10⁻¹⁵, so it never pollutes the comparisons below.
  • d₁, d₂the two standardized log-moneyness quantities. d₂ reuses d₁ — a shared intermediate, i.e. a node with fan-out.
  • Cthe call price — the graph's single scalar output. m = 1: reverse mode's favourite shape.

A vanilla desk wants four sensitivities of that one number. The closed forms exist here (that's why this example is honest — we can grade the sweep against them):

  • Δ = ∂C/∂Sdelta — the hedge ratio. The sweep will land on the S node with exactly Φ(d₁); the graph shows why.
  • ∂C/∂σvega — sensitivity to implied vol. Collected from two paths: σ√T and (r+σ²/2)T.
  • ∂C/∂r, ∂C/∂Trho and the calendar sensitivity (θ = −∂C/∂T). T has fan-out three: √T, (r+σ²/2)T, e⁻ʳᵀ — its adjoint sums three contributions.

Why should the full gradient be cheap? Look at the sums above: each sweep touches each edge exactly once, and the work per edge is one multiply-add using values already on the tape. So the backward sweep costs about what the forward pass cost — regardless of how many inputs are waiting at the far end. That intuition is a theorem:

The precise statement — the cheap-gradient principle

(Baur–Strassen.) Let f: ℝᵏ → ℝ be computed by a straight-line program (a computation graph of arithmetic operations and elementary functions) with evaluation cost C. Then the full gradient ∇f ∈ ℝᵏ is computable with cost at most 5·C, independent of k, by accumulating adjoints v̄ᵢ = Σ_{j∈ch(i)} v̄ⱼ · ∂vⱼ/∂vᵢ in reverse topological order, reading intermediate values from the tape. In practice the constant is 2–4. Forward mode instead costs Θ(k·C) for the same gradient; a full Jacobian of f: ℝᵏ → ℝᵐ costs min(k, m)·O(C) by choosing the sweep direction.

The twist — cheap in time, expensive in memory

The cheap-gradient theorem buys time with memory: the backward sweep reads the tape, so every forward intermediate must stay alive until the sweep returns. In deep learning that means training memory — not compute — is what caps batch size and context length, and it is why gradient checkpointing exists: keep only some checkpoints, recompute the forward chunks between them during the sweep, deliberately trading FLOPs back for memory. The identical constraint runs adjoint AAD on a Monte-Carlo book: one adjoint sweep per simulation gives every Greek, but only if the whole simulated path is stored (or regenerated) for the reverse pass. Forward mode needs no tape at all — it just pays its k passes. The tape asymmetry, not the chain rule, is what shapes the economics of both deep learning and production risk systems.

Why this matters · volarixs

A bucketed-vega report built the traditional way bumps one pillar at a time and reprices — the tall blue bar in the cost chart, growing with every pillar you add. Adjoint AD is the order-of-magnitude upgrade: one sweep per revaluation yields every pillar vega on the surface at once, exact to machine precision, for a constant ~4 pricings. The k-factor cost bars above are that trade, stated honestly — including the small-k regime where bumping is perfectly fine.

The graph habit transfers beyond Greeks: any gradient-calibrated object — a smile fit, a P&L-attribution regression, a neural forecaster feeding a Cross-Matrix cell — is trained by exactly this sweep, and the FD V-curve is the reason a "just bump it" gradient check needs its h chosen near ∛ε rather than "something small."
