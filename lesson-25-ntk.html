Lesson 25 · Wing V — training-dynamics mysteries

The neural tangent kernel & the lazy regime

Make a network wide enough and its weights stop moving — while the function it computes moves all the way to the data.

LevelUS PhDFR Master 2 advanced

Widen a network and something odd happens to its parameters: individually they barely move. Over an entire training run each weight in a width-m layer drifts by an amount of order 1/√m — at m = 10,000 that is a change of about one part in a hundred, against parameters of size 1 — and yet the function travels the whole distance from its random initialization to a fit of the training set. Both facts are true at once because there are m weights, and m tiny coordinated nudges add up to an O(1) change in the output. That observation has an exact consequence. If θ never leaves a shrinking neighbourhood of θ₀, then the first-order Taylor expansion of f in θ stops being an approximation and becomes exact in the limit, and a network linear in its parameters is a linear model with a fixed feature map — training it is kernel regression, with a kernel built from gradients. This lesson constructs that kernel, measures the laziness on real seeded training runs at five widths, and then reads the kernel's eigenvalues to predict in advance which part of the target gets learned first. Then the honest part: the regime where all of this is exactly true is precisely the regime in which nothing interesting can happen.

The words, before the machinery
  • width mthe number of hidden units in a layer. The limit m → ∞ is taken with the training set, the depth and the number of steps all held fixed. Lesson 21's N counted a real model's parameters and asked what loss they buy; here we take one layer to infinity as a mathematical device.
  • θ, θ₀, Pthe parameter vector, its value at initialization, and its length. θ ∈ ℝP. For the one-hidden-layer network below P = 3m. "Parameter space" is Lesson 9's weight space, now with P in the thousands.
  • parameterizationthe bookkeeping choice of how layer scalings, initial variances and learning rates depend on m. Three named ones matter: standard (what PyTorch does by default), NTK (an explicit 1/√m in front of each layer, which is what this lesson uses), and μP (maximal update). They differ only in powers of m — and they decide which limit you get.
  • lazy / richlazy: the features the network computes are frozen at their random initial values and only the read-out combination of them is fitted. rich: the features themselves move. Chizat, Oyallon & Bach's terminology (2019). "Lazy" is not an insult, it is a measurable property — three numbers below measure it.
  • Jacobian ∇θfthe row vector of ∂f(x)/∂θp over all P parameters. Exactly the object Lesson 13's backward sweep produces: one reverse pass per input gives this whole row, at the cost of a few forward passes.
  • tangent kernel Θthe inner product of two inputs' Jacobians. Lesson 6's reading of an inner product as a similarity, applied to gradients: two inputs are "similar" if moving a parameter moves both of their outputs the same way.
  • Gram matrixthe n×n table of pairwise kernel values on the training inputs, Θij = Θ(xi,xj). Symmetric positive semidefinite for the same reason XᵀX was in Lessons 6–7: it is a table of inner products.
  • gradient flowgradient descent with the step size taken to zero: the ODE θ̇ = −∇θL. The continuous-time idealization of Lesson 9's update. Everything on this page is run in discrete steps and read through the flow.
  • function spacetracking the n numbers f(xi) instead of the P numbers θp. The change of viewpoint that makes the whole lesson work: P is enormous and growing, n is fixed and small.
  • RKHSreproducing kernel Hilbert space — the space of functions a kernel can build, with its own notion of length ‖h‖Θ. All you need here: among functions that fit the data exactly, one has the smallest ‖·‖Θ, and kernel gradient descent from zero converges to that one. It is Lesson 22's min-norm interpolant with a different feature map.
  • spectral biasthe empirical fact that networks fit smooth, low-frequency structure before wiggly, high-frequency structure. In the lazy regime it stops being an empirical fact and becomes an eigenvalue ordering, computed in the second panel.
Step one — the network as a linear model

Take any differentiable f(x;θ) and expand it to first order in the parameters around initialization. Nothing here is special to networks; it is a Taylor expansion:

  • the tangent features of the input x: its Jacobian row at initialization. P numbers per input, computed once and then never updated. This is the whole meaning of "the features are frozen."
  • the parameter displacement, the only thing that moves. flin is linear in δ — so fitting it by least squares is Lesson 5's problem with design matrix rows φ(xi), and its geometry is Lesson 22's.
  • the random function the network computes before any training. An offset, not a feature. In the panels below it is removed exactly, by a trick described there, so every width starts from the zero function.

The concrete network used on this page is the smallest one that shows the effect — one hidden layer, scalar input, scalar output, written in the NTK parameterization (note the explicit 1/√m):

  • the NTK scaling. Without it, a sum of m random O(1) terms would be of size √m; with it the output is O(1) at every width, and — the point — each parameter's influence on the output is O(1/√m), which is why each one need only move that far.
  • = σ(wkx+bk)/√m; likewise ∂f/∂wk = akσ′(·)x/√m and ∂f/∂bk = akσ′(·)/√m. These 3m numbers are φ(x). Every one of them is O(1/√m) — the individual-influence statement, in symbols.
  • unit-variance Gaussian initialization. So ‖θ₀‖ ≈ √(3m) — the denominator of the relative-movement statistic below, and the reason the ratio carries a 1/√m.
Step two — the kernel is an inner product of gradients

A linear model has a kernel: the inner product of its feature vectors. For the tangent features that object is the neural tangent kernel.

  • the n×P Jacobian of the training outputs, row i = φ(xi)ᵀ. Lesson 13 built exactly this, one row per reverse sweep. Θ = JJᵀ is Lesson 6's table-of-all-inner-products, XᵀX, built over J's rows instead of its columns — the same Gram construction, entered from the other side.
  • symmetric positive semidefinite, always. vᵀΘv = ‖Σiviφ(xi)‖² ≥ 0 — no assumption needed, it is a Gram matrix (Lesson 6's spectral theorem then gives real non-negative eigenvalues and an orthonormal eigenbasis).
  • the kernel exists at every θ; the lazy claim is that it does not move. ‖Θθ_T − Θθ_0‖F/‖Θθ_0‖F is the number the first panel measures, with ‖·‖F the Frobenius norm — the square root of the sum of the squared entries. Zero drift = frozen features.
Step three — training, seen in function space

Now run gradient flow on the squared loss and watch the outputs rather than the weights. Write u(t) = (f(x₁;θt), …, f(xn;θt)) for the vector of training predictions. The chain rule does the rest, and the P-dimensional parameter dynamics collapse into an n-dimensional linear ODE — exactly, with no approximation, at any width:

  • the residual on the training set: n numbers. The whole of training, viewed from function space, is the decay of this vector. Note what has vanished: P.
  • the chain rule, once. This step is exact for any architecture and any width. The only place an approximation can enter is the subscript on Θθ_t.
  • the loss's gradient, expressed in function space. Compare Lesson 9: there the error contracted as (1 − ηλi) per step along each eigenvector of the Hessian, in weight space. Here the same structure appears in function space, with Θ in place of the Hessian.

Freeze the kernel — assume Θθ_t ≡ Θ — and the ODE is solved by a matrix exponential. Diagonalize Θ = Σᵢ λᵢ qᵢ qᵢᵀ with the spectral theorem of Lesson 6, and the coupled system falls apart into n independent scalar decays:

  • eigenvalue and eigenvector of the Gram matrix Θ. λi ≥ 0 because Θ ⪰ 0. A direction with λ = 0 is never learned at all: the residual there is untouched by training, forever.
  • the time constant of eigendirection i. Large eigenvalue → fast. Ratios of time constants are ratios of eigenvalues, so the condition number κ = λmax/λmin of Lessons 5, 9 and 22 is here literally the ratio between the fastest and slowest thing the model learns.
  • the time at which direction i's residual has fallen by 90%. e−λt = 0.1 ⇔ t = ln10/λ. This is the frontier line drawn in the second panel.

So if the kernel is constant, training is completely predictable from one eigendecomposition, done before a single step is taken. The rest of the lesson is about when that "if" holds, and what it costs.

The precise statement

The precise statement

(i) Linearization and the tangent kernel. Let f(·;θ) be differentiable in θ ∈ ℝP. Its first-order model at θ₀ is flin(x;θ) = f(x;θ₀) + ∇θf(x;θ₀)ᵀ(θ−θ₀), a model linear in θ with the fixed feature map φ(x) = ∇θf(x;θ₀), whose kernel is Θ₀(x,x′) = φ(x)ᵀφ(x′). Every Gram matrix built from Θ₀ is symmetric positive semidefinite, since vᵀΘ₀v = ‖Σᵢvᵢφ(xᵢ)‖² ≥ 0. Under gradient flow θ̇ = −∇θL with L = ½Σᵢ(f(xᵢ;θ)−yᵢ)², the training outputs obey exactly u̇ = −Θθ_t(u−y), with no approximation and at any width. If Θθ_t ≡ Θ is constant, then r(t) = e−Θtr(0), and in the eigenbasis Θ = Σᵢλᵢqᵢqᵢᵀ each coordinate obeys qᵢᵀr(t) = e−λᵢtqᵢᵀr(0), with time constant 1/λᵢ.

(ii) The infinite-width limit (Jacot, Gabriel & Hongler, 2018; Lee, Xiao, Schoenholz, Bahri, Novak, Sohl-Dickstein & Pennington, 2019). For a fully-connected network under the NTK parameterization with i.i.d. Gaussian initialization, as the hidden widths tend to infinity the initial kernel Θθ_0 converges in probability to a deterministic limit Θ∞ determined only by the architecture and the nonlinearity — the randomness of the draw washes out — and along gradient flow on a fixed training set over a fixed time horizon, Θθ_t converges to that same Θ∞, uniformly in t. Training is therefore exactly kernel gradient descent with a fixed kernel: u(t) = y + e−Θ∞t(u(0)−y). If Θ∞ is positive definite on the training inputs then u(t) → y, and the learned function change f∞ − f0 is the interpolant of the residuals y − u(0) with the smallest RKHS norm ‖·‖Θ∞ — the same "shortest exact fit" object as Lesson 22's minimum-norm interpolant X⁺y, with the tangent features φ in place of that lesson's random cosines. At large finite width m, Lee et al. show that with high probability the trained network and its own linearization stay within O(m−1/2) of each other, uniformly over the training horizon.

(iii) Scope — this is a regime, not a description. The limit is a property of the parameterization, not of width as such. Yang and Hu (2021) classify the width-scalings of layer multipliers, initial variances and learning rates, and show that each admissible scheme has either a kernel infinite-width limit, in which the features are frozen and the theorem above applies, or a feature-learning limit, in which they are not; μP is the unique scheme in which every layer learns features at width-independent scale. NTK parameterization sits on the kernel side by construction. Empirically, on the standard vision benchmarks where both sides have been measured carefully — CIFAR-10 above all — finite networks trained at standard settings outperform their own tangent kernels, so the lazy limit is a statement about what frozen random features can achieve — a useful lower bound and a solvable model — not a model of what training actually does.

See it — the spectrum decides the order of learning

Panel one measured a kernel; panel two uses one. To make every claim exact we switch to the closed-form infinite-width tangent kernel of a one-hidden-layer ReLU network. For unit-norm inputs it depends only on u = x̃ᵀx̃′, through the two arc-cosine kernels κ₀ = 𝔼[σ′σ′] and κ₁ = 𝔼[σσ]:

  • the contribution of the output weights: 𝔼[σ(wᵀx)σ(wᵀx′)] for w ~ 𝒩(0,I) and ReLU σ. Cho & Saul's arc-cosine kernel of degree 1. At u = 1 it equals ½ = 𝔼[ReLU(g)²].
  • the contribution of the hidden weights: (x̃ᵀx̃′)·𝔼[σ′σ′], with 𝔼[a²] = 1. κ₀(1) = ½: half the units are active at any input. So Θ∞(x,x) = 1 for unit-norm x, which is why every diagonal entry below is exactly 1.
  • the input, lifted to the unit sphere in ℝ³: x̃(α) = (cos α, sin α, 1)/√2, where α is the angle that indexes the input (φ stays reserved for the tangent features). n = 24 inputs equally spaced around the circle; the constant third coordinate is the first-layer bias. Then u = (cos Δα + 1)/2 depends only on the angular gap, so the Gram matrix is circulant — and the eigenvectors of a symmetric circulant matrix are exactly the discrete cosines and sines. Frequency indexes the eigenspaces, with no approximation.
  • the frequency labelling an eigenspace, ν = 0 … 12, with eigenvalue λν. Not the residual r of Step three: ν counts oscillations around the circle. ν = 0 is the constant mode, ν = 12 the fastest one the 24-point grid can carry; each ν between them spans a 2-dimensional eigenspace (a cosine and a sine), which is why the 13 frequencies account for 24 eigendirections.

Because the eigenvectors are literally Fourier modes, "which mode is learned first" is answered by sorting eigenvalues. The target is a seeded sum of nine unit-amplitude modes (frequencies ν = 0 to 8, seeded phases), so every frequency present enters with the same amplitude and none is favoured by the data — anything you see is the kernel's doing. Two things worth naming. First, the eigenvalues are strictly decreasing in frequency here — that is computed, not assumed, and it is what makes "smooth first" a theorem about this kernel rather than a slogan. Second, since every mode's learned fraction is 1 − e−λνt, the time to reach any fixed fraction scales as 1/λν; so the slowest mode takes exactly κ times as long as the fastest, whatever fraction you pick. Conditioning is not a nuisance here either — it is the ratio between what the model learns immediately and what it never gets to.

The twist — the theory works because the interesting part has been switched off

The NTK explains something real. In the lazy regime the loss is a convex quadratic in δ, so there are no bad local minima, no saddles to escape, and convergence is guaranteed at a rate you can compute before training; that is a large part of why very wide networks train reliably, and it is the honest answer to "why does a non-convex problem in a billion dimensions not get stuck." But look at what has been paid for it. A kernel method with a fixed kernel is precisely the class of model that deep learning beats — and the kernel here is fixed at a random initialization. Lesson 20's superposition, in which a network arranges features to pack more of them than it has dimensions, cannot happen: nothing arranges anything. Lesson 23's grokked circle, in which the network discovers a representation and then reorganizes onto it, cannot happen either: the representation is φ(x), fixed by the Gaussian draw on the first line and never touched again. Every mechanism this wing has been about is a feature-learning mechanism, and the lazy limit is the limit in which feature learning is exactly zero. The theory is the clean case because it is the empty case.

Second barrel, and it is the one that decides how much of this to believe: the parameterization chooses the regime. Nothing about "wide" forces laziness. Move the width-dependence between the layer multiplier, the initial variance and the learning rate and you get a different infinite-width limit — NTK scaling sends you to the frozen kernel, μP keeps the features moving at a width-independent scale, and the standard PyTorch defaults give no feature-learning limit at all, with the extra practical defect that their best learning rate drifts as you widen — exactly the drift μP removes. So the sentence "wide networks are kernel machines" is not a discovery about neural networks; it is a consequence of the units you chose to write them in. That is also the practical payoff: μP's width-independent hyperparameters, now standard for frontier training runs, come directly from asking which parameterizations avoid this lesson's limit.

Re-applied — the desk has been doing this since before it had a name

A linearized risk model is the same move, made for the same reason. Take a book value V(S, σ, r, …) and expand it to first order in the risk factors around today's marks: the Jacobian ∇V is the vector of Greeks, produced by exactly the adjoint sweep of Lesson 13, and the linearization ΔV ≈ ∇Vᵀ Δz is delta-vega-rho P&L attribution. It is a fixed-feature model in the same precise sense as flin: the features are the sensitivities, computed once at the current mark and then held constant while the factors move.

And its failure mode is the same one. The linearization is excellent for small moves and wrong exactly when the exposures themselves move — which is the gamma term, the second derivative that the first-order expansion discarded. Lazy is delta-only: the Greeks are frozen, so the book is a fixed linear function of the factors. Rich is the book that re-hedges: the exposures are functions of where the market went, and the P&L is not a linear read-out of anything computed this morning. The trade-off transfers intact, too — the linear model is the one you can solve in closed form, aggregate across the firm and explain to a risk committee, and it is the one that misprices the day the market moves enough to matter. "Feature learning is the gamma term" is not an analogy; it is the same Taylor expansion, truncated at the same place, failing for the same reason.

Why this matters · volarixs

A Cross-Matrix cell (Lesson 7) is a fixed-feature linear fit: the driver, its lags, the controls Z are chosen in advance and the coefficient is solved for. This lesson says something specific about replacing such a cell with a neural forecaster — namely, ask first which regime it will train in. If it trains lazily (wide layer, small effective learning rate, short run, output scaled down at init), you have not bought feature discovery; you have swapped a small hand-chosen feature set for a large random one and are running kernel ridge on it. That can still help, because random features are a genuinely richer basis than three named columns — but the honest benchmark for it is kernel ridge on those features, not "the linear cell", and the diagnostic is the one in the first panel: measure whether the kernel moved.

The second panel is directly usable as well. Stopping gradient flow at time t applies the filter 1 − e−λt to each eigendirection, and ridge with penalty λridge = 1/t applies λ/(λ+1/t); the two agree at both extremes (both ≈ λt when λt ≪ 1, both → 1 when λt ≫ 1) and differ in the middle, where at λt = 1 they read 0.632 against 0.500. So early stopping is a spectral filter, of the same family as the truncated pseudoinverse of Lesson 8 and the ridge of Lesson 22 — which is what bayesian_pooled_elasticity already is. On an ill-conditioned cell the small-λ directions are the ones that neither a short run nor a ridge will resolve, and sign_stability is what it looks like when you let them resolve anyway.
